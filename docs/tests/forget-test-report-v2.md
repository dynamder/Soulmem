### 1. 激活次数 cap 验证 ✅

### 2. 缺失记忆推测行为
当角色卡中某段记忆被删除时，LLM 在重构过程中的表现：
- **低缺失度 (20%)**: 接近原文，但会用人设库中相似角色**替换**被删除的人物（八意永琳 → 藤原妹红）
- **中缺失度 (37%)**: 核心关系保留，部分细节被同世界观信息填充
- **高缺失度 (75%)**: 仅保留极少量关键词，LLM 大量**创作**角色卡中不存在的新互动细节
