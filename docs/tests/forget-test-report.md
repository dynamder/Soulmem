## 总结

1. **遗忘曲线有效**: 48 小时未激活的节点缺失度高达 75%，20 次激活降低到 37%。
2. **激活次数上限生效**: 50 次（cap）与 200 次激活效果相同（20.63%），超出的激活次数不再影响遗忘。
3. **LLM 角色扮演效果**: 所有推理过程以十六夜咲夜的身份进行，输出内容自然融入了角色风格。
4. **字段对齐约束**: 缺失度低于 0.6 时，aliases 长度不增长；description 根据新 content 自动更新。
5. **信息偏差**: 高缺失度下 LLM 推测容易引入原内容中不存在的信息（如 "Rustacean"、"信仰之石"）。
