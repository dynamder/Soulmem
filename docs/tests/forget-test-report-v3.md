## 测试概要

激活次数测试的**初始内容**改为由 LLM（以咲夜身份）实时生成一段虚构的事件记忆，然后对该记忆执行遗忘操作，观察不同激活次数下记忆的退化程度。

---

## LLM 生成的咲夜记忆

> 大小姐某天突然想尝尝月之都的糕点，我赶在满月之夜取回了一些。蕾米莉亚大人和芙兰朵露大人品尝后都露出了满足的笑容，我看着她们开心的样子，内心也感到无比喜悦。

### 节点 A — 0 次激活（缺失度 75%）

**遗忘前**: 大小姐某天突然想尝尝月之都的糕点，我赶在满月之夜取回了一些。蕾米莉亚大人和芙兰朵露大人品尝后都露出了满足的笑容，我看着她们开心的样子，内心也感到无比喜悦。

**遗忘后**: 我曾造访月之都，在那里取回了失去的记忆。我和辉夜、永琳一起品尝月都的美酒，她笑得那么开心，我也感到了一丝久违的温暖。

📌 **分析**:
- 🟡 核心元素「月之都」「取回」被保留
- 🟡 情感基调保持正面（"温暖" VS "喜悦"）
- 🟡 事件完全改变（"取回糕点" → "取回记忆" + "共饮美酒"）

---

### 节点 B — 20 次激活（缺失度 37%）

**遗忘前**: 同上

**遗忘后**: 大小姐说今晚的满月让我想起月都的糕点，我赶在满月时精心模仿着制作了。芙兰朵露和米莉亚品尝后都露出了满足的笑容，看着她们开心的样子，我也感到由衷的喜悦。

📌 **分析**:
- 🟢 核心情节「月都糕点」「满月」「大小姐/芙兰朵露品尝」「满足的笑容」全部保留
- 🟡 「取回」→「模仿制作」（合理推断——月都糕点不可得，改为自制）
- 🔵 「蕾米莉亚大人」→「米莉亚」（缩写丢失）

---

### 节点 D — 50 次激活 cap（缺失度 20.6%）

**遗忘前**: 同上

**遗忘后**: 大小姐某天突然想尝尝月之都的糕点，我赶在满月之夜取回了一些。帕秋莉大人和芙兰朵露小姐品尝后纷纷露出满足的笑容，我看着她们开心的样子，内心也感到无比喜悦。

📌 **分析**:
- 🟢 句子结构、情节几乎完全保留
- 🟡 「蕾米莉亚」→ **「帕秋莉」**（角色混淆——同馆角色）
- 🟡 「芙兰朵露大人」→「芙兰朵露小姐」
- 🔵 末尾「无比喜悦」一字不差

---

### 节点 C — 200 次激活（超 cap，缺失度 20.6%）

**遗忘前**: 同上

**遗忘后**: 大小姐某天突然想尝尝月之都的糕点，我赶在满月之夜取回了一些。帕秋莉大人和芙兰朵露大小姐品尝后，露出了满足的笑容，我看着她们开心的样子，内心也感到无比喜悦。

📌 **分析**:

- 🔵 结尾一字不差

## 关键发现

### 1. 激活次数 cap 验证 ✅
```
D (50次) = 20.63%  ≈  C (200次) = 20.63%
```

### 2. 缺失度与内容退化

| 缺失度 | 退化特征 |
|--------|---------|
| **75%** | 核心事件改变，人设库中"已删除"的角色信息泄露，情感基调泛化 |
| **37%** | 情节骨架保留，部分细节被"合理化"替换（取回→自制），次要角色名称缩写 |
| **20.6%** | 情节完全保留，仅个别角色名发生同馆混淆（蕾米莉亚→帕秋莉） |

### 3. 删除记忆的"泄漏"现象
即使角色卡中「八意永琳」片段被删除，在高缺失度（75%）下 LLM 仍可能从训练数据中调用相关角色信息（辉夜、永琳）。低缺失度下则更依赖给定的角色卡上下文，混淆局限于同馆角色（蕾米莉亚→帕秋莉）。
