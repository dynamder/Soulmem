# 序章：一个记性不好的角色扮演 AI

想象你有一个数字伙伴。

你花了整整一个晚上和它聊你的童年、你的梦想、你最害怕的事。它表现得如此善解人意，你几乎忘了对面只是一个程序。第二天你打开应用，想继续昨晚的话题——

它完全不记得了。

不是它不在乎。是它根本没有"记性"这个器官。每一次对话，对它来说都是一次全新的相遇；它的"温柔""傲娇""关心你"，不过是一张写满形容词的角色卡，在每次对话开始时被重新贴上去。

这就是 SoulMem 想要改变的事情。

## 从"表演人类"到"成为人类"

一年前，当我们开始 Soul Plan 这个计划时，市面上已经有不少 AI 聊天应用。但它们大多有一个共同点：**角色的"人格"是静态的**——由提示词技巧和角色卡拼装而成。聊得久了，新鲜感褪去，就只剩下重复。

社区的大部分精力投入在"前端"：语音合成、Live2D 模型接入、和外部游戏联动……这些让角色*看起来*更鲜活。但很少有人认真对待"后端"——**记忆**。而没有记忆，一切都只是"表演一个人类"。

我们相信，想要创造真正的"赛博生命"，需要的不是更逼真的外壳，而是更接近人类的基础架构：**像人类一样思考，像人类一样记忆，才有可能像人类一样回复**——而不是"表演一个人类"。

这本书，就是 SoulMem 的设计记录。核心概念部分回答它*是什么*，系统概览部分把设计决策集中在一起回答*它为什么长成这样*，深入实现部分回答*它是怎么工作的*。

## 这本书怎么读

SoulMem 是 Soul Plan（一个更大的计划）的核心组件，一个专为角色扮演任务设计的记忆系统。它的代码是 Rust，但**核心概念部分不需要任何编程背景**；从系统概览开始，你会逐渐接触到数据结构与代码符号：

| 部分 | 内容 | 适合谁 |
|------|------|--------|
| **第一部分 · 安装与部署** | 如何跑起来 | 想先动手的人 |
| **第二部分 · 核心概念** | 三类记忆、记忆层级与生命周期 | 想理解 SoulMem 是什么的任何人 |
| **第三部分 · 系统概览** | 总体架构、设计决策、记忆模型、一次对话发生了什么 | 想了解架构、好奇"为什么"的人 |
| **第四部分 · 深入实现** | 算法细节、Crate 参考 | 想读代码/参与开发的人 |
| **第五部分 · 实践与贡献** | 跑起来、测试、如何参与 | 想动手的人 |

建议按顺序从上往下读：每一层都比上一层更深入，读到你觉得"够了"的地方停下来即可。
