# 记忆算法

SoulMem 的记忆算法包括检索（retrieve）、遗忘（forget）和巩固（consolidate）算法。

## 巩固算法

整合与巩固功能是记忆系统动态演化中重要的一环。在每一次工作循环中，状态经历了Idle->Working->Idle的转变。这会在滑动窗口产生大量新信息，也激活了工作记忆，其中部分记忆（取决于对话内容）被频繁地触及。这意味着它们很可能与新的记忆有关，但仍需进一步判断。现在来介绍它具体如何工作。  
滑动窗口的摘要被送入LLM，以产出新记忆节点。这些节点与活跃的工作记忆节点一同被送入LLM，依据其内容获取“应如何建立连接”的指示。最终，这些连接被写入数据库，成为长期记忆的一部分，能够持久保存。这一过程，使得角色不断地演化成为可能。

### 组件简介
| 组件 | 功能 |
| ------ | ------ |
| generate.rs | 由SlidingWindow摘要生成新记忆节点 |
| select.rs | 择取本轮循环中最活跃的k个节点，用于生成记忆节点间的边 |
| link.rs | 由新生节点、活跃节点，得到本次新生成的边 |
| persist.rs | 将本次巩固产物写入长期记忆 |
